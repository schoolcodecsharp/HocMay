# Font giao diện

Be Vietnam Pro, ba weight thực sự dùng: Regular (400), SemiBold (600), Bold (700).
Các file nguyên bản được lấy ngày 2026-09-30 từ
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/bevietnampro).
Tác giả: [Be Vietnam Pro Project Authors](https://github.com/bettergui/BeVietnamPro).
Giấy phép SIL Open Font License 1.1 nằm trong `OFL.txt` cùng thư mục.

Self-host để demo không cần gọi Google Fonts khi mở trang. CSS dùng `font-display: swap`;
preload duy nhất weight 400, các weight còn lại được trình duyệt tải khi cần.
Giữ toàn bộ glyph gốc, không subset làm mất dấu tiếng Việt hoặc dấu kết hợp.
